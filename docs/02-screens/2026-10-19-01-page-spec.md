## 성격

이 문서는 화면 단위 기능 명세의 정본이다. 와이어프레임은 이 문서가 확정된 뒤 그린다.

| 이 문서가 소유한다                                 | 소유하지 않는다 → 정본                                                                           |
| -------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| 화면 지도 (라우트, 탭, 화면 ID)                    | 기능 범위, MVP 포함·제외, 카테고리 목록 → [기획서](../01-product/2026-10-17-02-product-brief.md) |
| 공통 정책값 (입력 길이, 금액 범위, 기간 한도)      | 데이터 모델, API, 인증 라이브러리, 세션 저장 방식 → 3단계 `docs/03-data/`                        |
| 화면별 규칙, 구성, 상태, 오류 대응                 | 색, 글꼴, 간격 → 디자인 토큰 문서 (작성 예정)                                                    |
| 화면이 알아야 하는 정보 (3단계 데이터 설계의 입력) |                                                                                                  |

- **동기화 규칙**: 와이어프레임(`2026-10-19-02-wireframes.html`)은 이 문서의 화면 ID(SC-xx)를 그대로 쓴다. 와이어프레임 작업 중 화면 결정이 바뀌면 이 문서를 함께 고친다. 서술이 어긋나면 이 문서가 이긴다.
- 같은 값을 두 곳에 적지 않는다. 정책값은 [공통 정책값](#공통-정책값)에만 적고, 화면별 절은 그 표를 가리킨다.

## 화면 지도

```
/login                    SC-02 로그인                 (인증 전)

─── 로그인 후: 하단 탭 바 레이아웃 (SC-01) ───
/                         SC-03 월간 달력 (메인)        ?month=2026-10&date=2026-10-18
/categories               SC-04 카테고리별              ?from=2026-10&to=2026-10&category=food&sort=latest
/search                   SC-05 검색                    ?q=쿠팡&from=2025-11&to=2026-10 (전체 기간: &period=all)
/settings                 SC-10 설정

─── 로그인 후: 탭 바 없음 ───
/expenses/new             SC-06 지출 등록               ?date=2026-10-18
/expenses/[id]/edit       SC-06 지출 수정

─── 라우트가 아닌 것 (목록 화면 위에 열림) ───
?expense={id}             SC-08 지출 상세 바텀시트      SC-03·04·05 위에서 열린다
                          SC-07 계산기 바텀시트         SC-06 안에서 열린다
                          SC-09 반복 범위 선택          SC-06 저장 시, SC-08 삭제 시

(그 외 경로)              SC-11 404 페이지
```

**하단 탭 바**: 달력(`/`) · 카테고리(`/categories`) · **＋ 등록**(중앙, `/expenses/new`) · 검색(`/search`) · 설정(`/settings`)

### 화면으로 만들지 않는 것

| 항목                             | 이유                                                                           |
| -------------------------------- | ------------------------------------------------------------------------------ |
| 구버전 데이터 이전               | 본인 데이터 1회 이전이라 화면 없이 스크립트로 한다. 방법은 3단계에서 정한다    |
| 랜딩·소개 페이지                 | 홍보 계획이 미정이고 본인 실사용이 목적이다. `/login`이 첫 화면이다            |
| 온보딩·튜토리얼                  | 첫 로그인 후 빈 달력이 곧 시작 화면이다                                        |
| 주간·일간, 예산, CSV 내보내기 등 | MVP 제외 항목 → [기획서](../01-product/2026-10-17-02-product-brief.md) 5장·8장 |

## 공통 규약: 화면이 전부 따르는 것

### 레이아웃

- 모바일 단일 레이아웃이다. 콘텐츠 폭은 최대 480px, 그보다 넓은 화면(데스크톱)에서는 가운데 정렬한다. 최소 폭 320px까지 깨지지 않아야 한다.
- 터치 영역은 최소 44×44px.
- 라이트·다크 두 벌을 모든 화면이 지원한다. 선택은 SC-10에서 한다.

### 입력

- **허용 문자**: 이모지 허용. 보이지 않는 제어문자는 저장할 때 제거한다. 제목은 한 줄이라 줄바꿈·탭을 공백으로 바꾼다. 앞뒤 공백은 저장할 때 제거한다.
- **글자 수 한도**: 한도에서 입력을 막는다. 붙여넣기는 한도까지만 넣는다. 카운터(`n/25`)가 한도에 닿으면 강조해 이유를 보여준다.
- **금액**: 숫자만 받는다. 붙여넣기는 숫자만 골라낸다(`12,000원` → 12000). 맨 앞 0은 지운다. 9자리를 넘는 입력은 막는다.
- **개월 수·회차 입력**(정기지출 개월 수, 할부 회차, 반복 범위의 N): 숫자 입력칸 + 뒤에 단위(`개월`, `회`) 고정 표시. 숫자 키패드, 숫자만 받고 최대 2자리, 맨 앞 0은 지운다. 붙여넣기는 숫자만 골라 2자리에서 자른다. 기본값은 비우고 placeholder로 범위를 보여준다 (예: `2~99`).
  - 오류 (폼 검증 시점과 같다): 빈칸 "개월 수를 입력해 주세요." / "회차를 입력해 주세요.", 정기·할부에 1 입력 "2부터 입력할 수 있습니다.", 반복 범위의 N이 남은 건수 초과 "{남은 건수}개월까지 입력할 수 있습니다."
  - 미리보기(기간·건수)는 값이 유효할 때만 갱신하고, 유효하지 않으면 비운다.
- **폼 검증**: [저장]은 늘 활성이다 (요청 중·오프라인만 비활성). 누르면 모든 필드 오류를 표시하고 첫 오류 칸으로 스크롤·포커스한다. 한 번 벗어난 칸은 그때부터 벗어날 때마다 검증한다. 입력 중에는 오류를 지우기만 하고 새로 띄우지 않는다.

### 상태를 URL에 둔다

- 조회 조건(월, 선택 날짜, 기간, 카테고리, 정렬, 검색어)과 열린 상세 바텀시트(`?expense=`)는 URL 쿼리에 둔다. 새로고침, 뒤로 가기, PWA 재실행 후에도 보던 화면이 유지된다.
- 쿼리가 없으면 기본값을 쓴다. 쿼리 값이 잘못됐으면(형식 오류, 범위 초과) 오류를 내지 않고 기본값으로 바꿔 URL을 교체한다.
- 조회 조건 변경은 히스토리를 쌓지 않는다(`replace`). 바텀시트 열기는 히스토리를 쌓는다(`push`) — 뒤로 가기가 시트를 닫아야 하기 때문이다.

### 로딩

- 첫 로딩은 화면 모양의 스켈레톤을 보여준다.
- 조건을 바꿔 다시 불러올 때(월 이동, 기간·필터 변경)는 이전 데이터를 보여준 채 갱신한다. 화면이 깜빡이지 않게 한다. 이 조회가 실패하면 이전 조건의 데이터를 남기지 않고 영역을 "불러오지 못했습니다" + [다시 시도]로 바꾼다 (다른 조건의 데이터를 보여주지 않기 위해).
- 무한 스크롤 추가 로딩은 목록 끝에 작은 로딩 표시.
- 자동 주기 갱신(폴링)은 없다. 저장·수정·삭제 후 관련 조회를 다시 불러온다.
- **같은 조건으로** 다시 불러오다 실패하면 보이던 데이터는 지우지 않고, 영역 위에 실패 띠 "최신 내용을 불러오지 못했습니다" + [다시 시도]를 보여준다. 해당하는 경우: 저장·수정·삭제 직후, 앱으로 돌아왔을 때, 연결이 다시 됐을 때.
- 무한 스크롤 다음 장이 실패하면 목록 끝에 "더 불러오지 못했습니다" + [다시 시도]. 자동 재시도는 하지 않는다.

### 빈 상태는 두 갈래다

- **기록이 0건**: "기록이 없습니다" + 기록하기 유도.
- **조건 결과 없음** (필터·검색): "조건에 맞는 기록이 없습니다" 계열 문구.
- 두 문구를 같게 쓰지 않는다. 필터를 걸어둔 것을 잊으면 고장으로 보이기 때문이다.

### 오류

| 상황                                     | 화면 대응                                                                           |
| ---------------------------------------- | ----------------------------------------------------------------------------------- |
| 입력값 오류                              | 해당 필드 아래 인라인 문구. 서버 검증 실패도 필드에 연결한다                        |
| 조회 실패 (네트워크, 5xx)                | 화면 영역 안에 "불러오지 못했습니다" + [다시 시도]                                  |
| 저장·삭제 실패                           | 알림 다이얼로그 "저장하지 못했습니다. 다시 시도해 주세요." 입력값은 그대로 둔다              |
| 세션 만료 (401)                          | → [RT 라우팅과 세션](#rt-라우팅과-세션)                                             |
| 대상 없음 (404: 다른 기기에서 이미 삭제) | 알림 다이얼로그 "이미 삭제된 기록입니다" → [확인] 후 관련 목록 다시 불러오기                           |
| 오프라인 | 상단 배너 "오프라인 상태입니다. 연결되면 다시 기록할 수 있습니다". 서버에 쓰는 버튼(저장·삭제·탈퇴) 비활성. 화면 이동·입력은 막지 않는다 |

### 다이얼로그, 바텀시트

| 종류                | 쓰는 곳                                                                                   | 닫는 방법                                         |
| ------------------- | ----------------------------------------------------------------------------------------- | ------------------------------------------------- |
| **바텀시트**        | 선택·보조 입력: 상세(SC-08), 계산기(SC-07), 연·월 선택, 기간 선택, 날짜 선택, 범위 선택(SC-09) | 아래로 끌기, 바깥 영역 탭, 뒤로 가기              |
| **드롭다운 메뉴** | 버튼 아래 펼치는 메뉴: 정렬(SC-04) | 항목 선택, 바깥 영역 탭 |
| **확인 다이얼로그** | 되돌릴 수 없는 행위: 삭제, 회원 탈퇴, 작성 중 이탈                                        | 버튼만 ([취소] / 실행). 바깥 탭으로 닫히지 않는다 |
| **알림 다이얼로그** | 오류·경고: 저장·삭제 실패, 이미 삭제된 기록 | [확인] 버튼 하나로만 닫힌다 |

- 다이얼로그는 화면 가운데에 띄운다. 확인 다이얼로그와 알림 다이얼로그는 같은 컴포넌트이고 버튼 수(2개/1개)만 다르다.
- 토스트는 쓰지 않는다. 사용자 조작 없이 나타났다 사라지는 알림은 놓치기 쉽기 때문이다.
- 성공 알림은 따로 띄우지 않는다. 결과가 화면에 바로 보인다 (달력에 반영, 목록에서 사라짐).
- 바텀시트 높이는 내용만큼, 최대 화면 높이의 90%. 넘치면 시트 안에서 스크롤한다. 키보드가 올라오면 시트를 키보드 위로 올린다.
- 다이얼로그는 한 번에 하나만 띄운다. 바텀시트 위에 다이얼로그는 띄울 수 있다(시트는 유지). 바텀시트 위에 바텀시트는 띄우지 않는다.
- 실행 버튼은 요청 중 비활성화한다 (중복 제출 방지). 요청 중에는 같은 화면의 다른 실행 버튼과 [뒤로]도 막는다.
- 위험한 실행 버튼(삭제, 탈퇴)은 danger 색 채움 버튼을 쓴다 (테두리형 없음).

### 문구

- 합니다체를 쓴다. 예: "기록이 없습니다", "삭제하시겠습니까?"
- 이 문서의 문구는 초안이다. 세부 문구는 사용자가 다듬는다.
- 필드 오류 문구 같은 반복 문구는 한 곳(상수)에 모은다. 화면마다 복제하지 않는다.

### 날짜 표시

| 위치                 | 형식                                                |
| -------------------- | --------------------------------------------------- |
| 달력 헤더, 기간      | `2026년 10월`, `2025년 11월 ~ 2026년 10월`          |
| 날짜 목록 헤더, 상세 | `10월 18일 (일)`, 다른 해면 `2025년 10월 18일 (토)` |
| 목록 항목의 날짜     | `10.18`, 조회 범위가 여러 해에 걸치면 `2025.10.18`  |

- 긴 텍스트: 목록의 제목·보조 줄은 한 줄 말줄임, 금액은 줄이지 않는다. 상세는 전부 줄바꿈해서 보여준다.

## 화면별 명세

### RT: 라우팅과 세션

#### 규칙

- 로그인이 필요한 경로에 세션 없이 들어오면 `/login?next={원래 경로+쿼리}`로 보낸다.
- `next`는 이 서비스 안의 경로(`/`로 시작, `//` 아님)만 받는다. 아니면 무시하고 `/`로 보낸다 (외부 주소로 넘어가는 리다이렉트 방지).
- 세션이 있는 채로 `/login`에 들어오면 `next` 또는 `/`로 보낸다.
- 세션 만료(401)는 어느 화면에서든 같은 처리다: `/login?next={현재 경로}&reason=expired`로 보낸다. 로그인 화면이 만료 안내 문구를 보여준다.
- 작성 중이던 등록·수정 폼에서 만료되면 입력값은 잃는다. 1인 사용·짧은 입력이라 복원 장치를 두지 않는다.
- 세션 유지 기간과 저장 방식은 3단계에서 정한다. 화면은 "세션이 있는가"만 안다.

### SC-01: 레이아웃과 하단 탭 바

### SC-03: 월간 달력

`/` · 쿼리 `month=YYYY-MM`, `date=YYYY-MM-DD`

#### 규칙

- 기본값: `month` = 이번 달, `date` = 오늘.
- 다른 달로 이동하면 선택 날짜는 그 달이 이번 달이면 오늘, 아니면 1일.
- `date`가 `month`에 속하지 않으면 `date`를 무시하고 위 규칙으로 정한다.
- 이동 수단:
  - 헤더의 이전·다음 달 버튼
  - 달력 영역 좌우 스와이프: 왼쪽으로 밀면 다음 달, 오른쪽으로 밀면 지난달. 미는 동안 이번 달과 옆 달이 손가락을 따라 움직이고, 화면 폭의 약 1/4 이상 밀거나 빠르게 튕기면 넘어가며, 덜 밀면 제자리로 돌아온다. 위아래 스크롤은 막지 않는다.
  - 헤더의 연·월을 누르면 연·월 선택 바텀시트
- 이동 범위는 [선택 가능 연도](#공통-정책값) 안이다. 가장 오래된 기록이 있는 해의 1월에 닿으면 [‹]를 비활성화하고 오른쪽 스와이프는 제자리로 돌아온다. 미래 쪽은 막지 않는다 (기술 상한에서만 [›] 비활성).
- 이번 달이 아닌 달을 보고 있으면 헤더에 [오늘] 버튼을 보여준다. 누르면 이번 달, 오늘로 간다.

#### 페이지 구성안

- **헤더**
  - `2026년 10월 ▾` (누르면 연·월 선택), [‹] [›], [오늘](조건부)
  - 월 합계: "10월 지출 1,234,500원"
- **달력**
  - 일요일 시작, 요일 표시줄 `일 월 화 수 목 금 토`. 일요일만 빨강, 토요일은 평일보다 낮은 회색. 공휴일은 표시하지 않는다.
  - 칸: 날짜 숫자 + 그날 합계(0원이면 비움). 금액은 칸에 들어가면 전체, 넘치면 [축약 표시](#공통-정책값).
  - 오늘: 날짜 숫자에 테두리 원. 선택한 날짜: 채운 원.
  - 앞뒤 달의 날짜는 흐리게 보여주고 누를 수 없다.
  - 항상 6줄로 그린다. 5줄 이하인 달은 다음 달 날짜로 채운다. 달을 넘겨도 달력 높이가 바뀌지 않는다.
- **선택한 날짜의 목록** (달력 아래)
  - 요약: 선택한 날짜 `10월 18일 (일)` · 그날 건수 · 그날 합계
  - 항목: 카테고리 아이콘 · 제목 · 반복 배지(`정기` / `할부 3/12`) · 금액. 제목이 길면 한 줄에서 말줄임(…), 배지·금액은 항상 보인다
  - 순서: 먼저 등록한 것이 위
  - 항목을 누르면 SC-08 상세 바텀시트

**연·월 선택 바텀시트**

- 연도 좌우 이동 + 1~12월 격자. 선택 가능 연도 밖으로는 이동할 수 없다(가장 오래된 기록이 있는 해에서 ‹ 비활성, 기술 상한에서 › 비활성). 기록 없는 달도 고를 수 있다.
- 지금 보고 있는 달은 채움, 이번 달은 테두리로 표시한다.
- 월을 누르면 바로 적용하고 닫힌다.

#### 상태

| 상태                | 처리                                                             |
| ------------------- | ---------------------------------------------------------------- |
| 첫 로딩             | 달력 격자 + 목록 스켈레톤                                        |
| 월 이동 중          | 이전 달 금액을 지우고 날짜만 먼저 그린 뒤 금액을 채운다          |
| 선택한 날 기록 없음 | "기록이 없습니다" + [기록 추가하기] → `/expenses/new?date=` |
| 조회 실패           | 달력 영역에 [다시 시도]                                          |

### SC-04: 카테고리별

`/categories` · 쿼리 `from=YYYY-MM`, `to=YYYY-MM`, `category={슬러그}`, `sort=latest|amount`

#### 규칙

- 기본값: `from` = `to` = 이번 달 (1일~말일), `category` 없음(= 전체), `sort` = `latest`.
- 기간은 시작 연·월 ~ 끝 연·월. `from ≤ to`, 최대 [60개월](#공통-정책값). 어기는 쿼리는 기본값으로 바꾼다.
- 비중은 **선택한 기간의 총지출 안에서** 각 카테고리가 차지하는 비율이다. 예: 2025년 11월 ~ 2026년 10월이면 그 12개월 총지출 기준.
- 이전 기간과의 증감 비교는 하지 않는다.
- 비중 그래프의 줄을 누르면 카테고리 필터가 그 카테고리로 바뀐다. 이미 선택된 줄을 다시 누르면 전체로 돌아간다. 필터 칩과 같은 상태를 공유한다.

#### 페이지 구성안

- **기간 드롭다운 + [기간 선택] 버튼** (헤더)
  - 드롭다운: 이번 달 · 최근 3개월 · 최근 6개월 · 최근 1년. 고르면 바로 적용한다. 지금 기간은 면 강조로 표시한다 (체크 표시 없음)
  - 라벨: 빠른 선택과 같으면 그 이름, 직접 정한 기간이면 `2026년 11월` / `2025년 3월 ~ 2026년 2월`. 직접 정한 기간이 적용 중이면 메뉴 맨 위에 그 기간을 강조해 보여준다
  - [기간 선택] 버튼(달력 아이콘): 기간 선택 바텀시트를 연다
- **요약**: 총지출 금액 · 건수
- **비중 가로 막대 그래프**
  - 지출이 있는 카테고리만, 금액 큰 순으로 한 줄씩
  - 한 줄: 카테고리 아이콘·이름 · 막대(폭 = 비중) · 비율 · 금액
  - 비율은 소수 첫째 자리까지 (예: `32.4%`). 합이 100.0%가 되도록 맞추지 않는다. 0.1% 미만은 `<0.1%`, 막대는 최소 폭 2px로 보이게 한다.
  - 금액이 같으면 카테고리 고정 순서(기획서 4-6)
  - 필터가 선택돼 있으면 그 줄을 강조하고 나머지는 흐리게
- **카테고리 필터 칩**: 전체 + 10개, 한 줄 가로 스크롤 (한 화면에 다 담지 않는다). 지출이 없는 카테고리도 고를 수 있다. 그래프 줄로 필터를 바꾸면 칩 줄이 그 칩이 보이도록 자동 스크롤한다.
- **내역 목록**
  - 목록 요약: 선택한 칩 · 건수 · 합계. 전체면 `전체 · 42건 · 1,234,500원`, 필터 시 `식비 · 23건 · 345,700원`. 오른쪽에 정렬 드롭다운 메뉴 `최신순 ▾` / `큰 금액순`. 고르면 즉시 적용하고 목록 맨 위로
  - 정렬: 최신순 = 날짜 내림차순. 큰 금액순 = 금액 내림차순, 같으면 날짜 내림차순.
  - 항목: 카테고리 아이콘 · 제목 · 날짜 · 반복 배지 · 금액
  - 무한 스크롤 ([한 번에 50건](#공통-정책값))
  - 항목을 누르면 SC-08 상세 바텀시트

**기간 선택 바텀시트**

- 시작·끝 두 칸 중 하나를 고르고, 아래 연도 이동 + 월 격자로 정한다. 열 때는 시작 칸이 선택돼 있다. 시작~끝 사이 달은 옅게 채운다.
- 이번 달 이후의 미래 달도 고를 수 있다 (미리 등록해 둔 정기·할부 확인). 범위는 [선택 가능 연도](#공통-정책값).
- 끝 칸을 고르는 동안 시작보다 앞선 달은 비활성. 시작을 끝보다 뒤로 고르면 끝을 시작과 같게 맞춘다.
- 빠른 선택은 두지 않는다 (드롭다운이 맡는다). 시트는 시작·끝을 직접 정할 때만 쓴다.
- [적용] — 비활성화: 60개월 초과. 비활성 이유를 버튼 위에 표시 ("최대 5년까지 조회할 수 있습니다"). 적용해도 카테고리 필터·정렬은 유지한다.

#### 상태

| 상태                        | 처리                                               |
| --------------------------- | -------------------------------------------------- |
| 기간에 기록 없음            | 그래프·목록 자리에 "해당 기간 내 기록이 없습니다" |
| 필터한 카테고리에 기록 없음 | 목록 자리에 "해당 기간 내 {카테고리} 기록이 없습니다" |
| 조회 실패                   | 영역별 [다시 시도]                                 |

### SC-05: 검색

`/search` · 쿼리 `q`, `from=YYYY-MM`, `to=YYYY-MM` 또는 `period=all`

#### 규칙

- **제목 또는 내용**에 검색어가 들어간 기록을 찾는다 (부분 일치, 영문 대소문자 무시). 초성 검색은 하지 않는다.
- 검색어는 앞뒤 공백을 제거하고 [1~50자](#공통-정책값)일 때 검색한다. 띄어쓰기가 있어도 단어로 나누지 않고 전체 문자열을 그대로 부분 일치로 찾는다. 특수문자(`%`, `_` 등)는 글자 그대로 찾는다.
- 입력을 멈추고 0.3초 뒤 자동 검색. 키보드의 검색(Enter)은 즉시 검색.
- 기간 조건이 있다. 기본값은 최근 1년이고, [전체 기간](#공통-정책값)으로 넓힐 수 있다. 카테고리 조건은 없다.
- 쿼리: `from`·`to`(YYYY-MM) 또는 `period=all`. 둘 다 없으면 최근 1년. 잘못된 값은 기본값으로 바꾼다.
- 검색어를 바꿔도 기간은 유지한다.
- 결과는 날짜 내림차순, 무한 스크롤.

#### 페이지 구성안

- 검색 입력: 검색어(`q`) 없이 들어오면 자동 포커스. 결과가 있는 상태로 돌아올 때(상세 닫기, 뒤로 가기)는 키보드를 올리지 않는다. 입력이 있으면 [지우기] 버튼 (누르면 검색 전 상태 + 포커스)
- 자동 검색 중: 이전 결과를 흐리게 유지하고 입력창 오른쪽에 작은 로딩 표시
- 기간 드롭다운 + [기간 선택] 버튼 (검색 입력 아래): SC-04와 같은 구조
  - 드롭다운에 **전체 기간**이 더 있다: 전체 기간 · 이번 달 · 최근 3개월 · 최근 6개월 · 최근 1년
  - 전체 기간 = 가장 오래된 기록 ~ 이번 달 말일. 다음 달 이후 기록은 넣지 않는다. 그 기록은 기간 선택 바텀시트로 직접 정해서 찾는다
  - 기간 선택 바텀시트는 SC-04와 같다. 차이: 60개월 제한이 없다
- 검색 결과 요약 (결과 목록 위): 선택한 기간에서 검색어와 일치한 기록의 건수 · 금액 합계. 어느 기간인지 함께 보여준다. 예: `최근 1년 · 23건 · 345,000원`
- 결과 목록: 월 단위로 묶어 `2026년 10월` 구분 줄을 둔다
  - 항목: 카테고리 아이콘 · 제목 · 날짜 · 금액. 내용에서 일치했으면 일치 부분 주변 한 줄을 날짜 옆에 보여준다
  - 일치한 부분을 강조한다. 제목과 내용 모두 일치하면 제목만 강조
  - 항목을 누르면 SC-08 상세 바텀시트
- 검색 전 화면: 안내 문구 "제목이나 내용으로 검색할 수 있습니다". 최근 검색어는 두지 않는다.

#### 상태

| 상태      | 처리                              |
| --------- | --------------------------------- |
| 결과 없음 (전체 기간이 아닐 때) | "해당 기간 내 '{검색어}'와 일치하는 기록이 없습니다". 다른 기간은 기간 드롭다운이나 기간 선택으로 바꾼다 |
| 결과 없음 (전체 기간) | "'{검색어}' 검색 결과가 없습니다" |
| 조회 실패 | 결과 영역에 [다시 시도]           |

### SC-06: 지출 등록·수정

`/expenses/new?date=YYYY-MM-DD` · `/expenses/[id]/edit`

#### 규칙

- 등록의 날짜 기본값: 쿼리 `date`, 없거나 잘못됐으면 오늘.
- 수정은 기존 값을 채워서 연다. 대상이 없으면(404) 알림 다이얼로그 "이미 삭제된 기록입니다" → [확인] 후 `/`로 보낸다.
- 반복 건(정기·할부)을 수정하면 저장 버튼을 누를 때 SC-09 범위 선택을 거친다.
- 수정 화면에서 반복 종류(없음·정기·할부)는 바꿀 수 없다. 바꾸려면 삭제 후 다시 등록한다.
- 저장 성공
  - 등록: `/?month={저장한 날짜의 월}&date={저장한 날짜}`. 히스토리를 교체해 뒤로 가기로 폼에 돌아오지 않는다.
  - 수정: 이전 화면으로 돌아간다 (상세 바텀시트는 닫힌 상태).
- 입력한 내용이 있는 상태에서 뒤로 가기·취소하면 확인 다이얼로그 "작성 중인 내용이 사라집니다. 나가시겠습니까?". "입력한 내용이 있다" = 처음 값(수정은 원래 값)과 하나라도 다름. 버튼은 [계속 작성](주 버튼) / [나가기](회색 보조 버튼, 위계가 낮다). 세부 스타일은 디자인 토큰에서 정한다.
- 반복 종류를 바꿨다 돌아와도 화면을 떠나기 전까지 종류별 입력값을 유지한다.

#### 페이지 구성안

상단: [‹ 뒤로] · 제목 `기록하기` / `수정하기`. 탭 바 없음.

| 필드     | 입력 방식                                                                                 | 검증                                |
| -------- | ----------------------------------------------------------------------------------------- | ----------------------------------- |
| 날짜 | 누르면 날짜 선택 바텀시트(직접 만든 달력, SC-03 달력 컴포넌트 재사용). `2026년 10월 18일 (일)`로 표시. 반복을 고르면 라벨이 "날짜 (첫 결제일)" / "날짜 (1회차 결제일)" | [선택 가능 연도](#공통-정책값) 안. 미래 날짜 허용 |
| 제목     | 텍스트, 글자 수 표시 `12/25`, 아래에 **자주 쓴 제목 추천**                                | 필수, [1~25자](#공통-정책값)        |
| 카테고리 | 아이콘 격자 4열에서 하나 선택. 10개라 4·4·2로 놓이고, 마지막 줄 2개는 왼쪽 정렬. 선택한 칸을 다시 눌러도 해제되지 않는다 | 필수                                |
| 금액     | 숫자 키패드(`inputmode="numeric"`), 입력 중 쉼표, 뒤에 "원". 오른쪽에 [계산] 버튼 → SC-07 | 필수, [1~999,999,999](#공통-정책값) |
| 내용     | textarea(여러 줄 입력칸). 기본 높이 3줄, 6줄까지 늘고 그 뒤는 칸 안에서 스크롤. 글자 수 표시 `0/200` | [0~200자](#공통-정책값)             |
| 반복     | 3단 선택: 없음 / 정기지출 / 할부. 고르면 아래에 반복 입력이 펼쳐진다                      | 아래 표                             |

- [저장] 버튼 (하단 고정) — 늘 활성. 비활성화: 요청 중, 오프라인. 검증은 [폼 검증](#입력) 규칙을 따른다.
- 필드 오류 문구: 제목 빈칸 "제목을 입력해 주세요.", 카테고리 미선택 "카테고리를 선택해 주세요.", 금액 빈칸·0 "금액을 입력해 주세요.", 할부 총액 < 회차 수 "총액은 회차 수 이상이어야 합니다."

**자주 쓴 제목 추천**

- 제목 입력에 포커스가 있고 1자 이상 입력했을 때, 입력창 바로 아래에 목록으로 보여준다.
- 매칭: 앞부분 일치 + 초성 일치. 한글을 자모로 분해해 비교하므로 치는 도중(`쿺`)에도 끊기지 않는다.
- 대상·개수·순서: [공통 정책값](#공통-정책값)의 제목 추천.
- 항목: 제목 + 마지막으로 쓴 카테고리 아이콘.
- 고르면 제목을 채우고, 그 제목에 마지막으로 쓴 카테고리를 채운다. 카테고리를 이미 골라둔 상태면 바꾸지 않는다.
- 목록을 닫는 조건: 일치 0건, 바깥 탭, 입력칸 벗어남, 입력값과 완전히 같은 제목 하나만 남음.
- 키보드의 다음·완료 키는 추천을 고르지 않고 다음 칸으로 간다.
- 추천 목록은 화면 진입 시 한 번 받아 온다. 입력 중 서버 요청은 없다.

**반복 입력**

| 반복     | 입력                                                                     | 미리보기                                                                                                                     |
| -------- | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| 정기지출 | 결제일 = 날짜 필드의 일 (따로 입력하지 않는다). 기간: 계속 / N개월(2~99, 숫자 입력) | `매달 18일 · 계속`, `2026년 10월 ~ 2027년 3월 (6건)`. 29~31일이면 `없는 달은 말일` 덧붙임 ([결제일이 없는 달](#공통-정책값)) |
| 할부     | 회차 2~99(숫자 입력). 금액 기준: 회차당 금액 / 총액. 결제일은 정기지출과 같다       | 총액이면 `회차당 33,333원 · 첫 회 33,334원` (끝전은 첫 회에)                                                                 |

- 할부 총액 기준이면 금액 필드 라벨이 "총액"이 되고, 총액 ≥ 회차 수여야 한다 (회차당 1원 이상).
- 할부 저장 결과: 날짜 필드의 날짜를 1회차로, 매달 같은 일에 회차 수만큼 기록이 만들어진다. 그 일이 없는 달은 [말일](#공통-정책값)이다.
  - 예: 2026년 10월 31일 · 총액 100,000원 · 3회 → 10월 31일 33,334원(1/3), 11월 30일 33,333원(2/3), 12월 31일 33,333원(3/3)
  - 회차당 금액 기준이면 모든 회차가 입력한 금액이고, 총액은 회차당 금액 × 회차 수다.
  - 1회차는 날짜 필드의 날짜다. 청구 시작일이 결제한 날과 다르면 날짜 필드에 첫 청구일을 골라 등록한다. 예: 9월 18일에 30만 원을 3개월 할부로 결제하고 11월 1일부터 청구되면, 날짜를 11월 1일로 고르고 할부 3회 → 11월 1일, 12월 1일, 1월 1일에 각 100,000원
- 반복 기록은 같은 제목·카테고리·내용으로 만들어지고, 할부는 목록·상세에 회차(`3/12`)를 표시한다.
- 수정 화면에서는 반복 3단 선택, 정기 기간(계속 / 개월 수), 할부 금액 기준과 회차 수가 지금 값을 채운 채 비활성이고 "반복 종류와 기간은 바꿀 수 없습니다."를 보여준다. 반복 없는 기록도 정기·할부로 바꿀 수 없다.
  - 바꿀 수 있는 것: 날짜 · 제목 · 카테고리 · 금액 · 내용. 반복 기록은 [저장] 때 SC-09에서 범위를 고른다.
  - 이유: 종류·기간·회차를 바꾸면 이미 만들어진 건들을 다시 만들어야 해서 건별 범위 수정과 함께 쓸 수 없다.
  - 바꾸려면 삭제 후 다시 등록한다. "계속" 정기지출을 끝내려면 삭제에서 "이후 전체"를 고른다.

#### 오류와 화면 대응

| 상황                   | 화면 대응                                                                           |
| ---------------------- | ----------------------------------------------------------------------------------- |
| 필수값 누락 | [저장]을 누르면 필드 아래 문구 + 첫 오류 칸으로 이동. 범위 초과는 입력 단계에서 막아 오류가 생기지 않는다 |
| 저장 실패              | 알림 다이얼로그, 입력값 유지 |
| 수정 저장 시 404       | 알림 다이얼로그 "이미 삭제된 기록입니다" → [확인] 후 `/` |

### SC-07: 계산기 바텀시트

SC-06의 [계산]에서 연다.

#### 규칙

- 연산: 더하기, 빼기, 곱하기, 나누기. 1/n은 `÷ n`이다.
- 곱하기·나누기를 더하기·빼기보다 먼저 계산한다 (일반 계산기 우선순위).
- 금액 필드에 값이 있으면 그 값을 첫 숫자로 넣고 시작한다.
- **끝전 처리**: 단위(1원 / 10원 / 100원) × 방향(올림 / 버림). 기본값 1원·버림 (소수점 버림). 결과에만 적용한다.
- [적용]하면 금액 필드에 결과를 넣고, 계산식을 내용에 한 줄 덧붙인다.
  - 형식: `36,000 ÷ 3 = 12,000`, 끝전 처리를 했으면 `(10원 올림)` 덧붙임
  - "계산식을 내용에 기록" 체크(기본 켜짐)
  - 덧붙이면 200자를 넘는 경우: 적용하기 전에 결과 미리보기 아래에 "내용이 200자를 넘어 계산식은 기록되지 않습니다"를 표시한다. [적용]하면 금액만 넣는다
- 식 입력: 숫자 하나 최대 9자리, 연산자 최대 10개. 연산자를 연달아 누르면 마지막 것으로 바꾼다. 식 맨 앞에는 연산자를 넣을 수 없다(음수로 시작하지 않는다). 소수점 키는 없다.
- 결과 미리보기: 입력할 때마다 갱신. 식이 연산자로 끝나면 직전까지 계산한 값을 흐리게 보여준다. 나누기가 있으면 끝전 처리 전 값을 작게, 처리 후 값을 크게 보여준다.
- 계산식 기록 위치: 내용 끝에 새 줄로 붙인다 (내용이 비어 있으면 첫 줄). 여러 번 적용하면 줄이 쌓인다.
- 바깥 탭·아래로 끌기·뒤로 가기는 적용 없이 닫는다.

#### 페이지 구성안

- 식 표시줄 + 결과 미리보기
- 끝전 처리 선택: 단위 3개, 방향 2개 (나누기가 있을 때만 보인다)
- 키패드: `7 8 9 ÷` / `4 5 6 ×` / `1 2 3 −` / `00 0 ← +` / `C` · [적용]. ←는 한 글자 지우기, C는 식 전체 지우기
- [적용] — 비활성화: 식이 완성되지 않음, 결과가 1~999,999,999원 밖, 0으로 나눔. 결과 미리보기 아래에 이유 표시 ("결과가 1원 이상이어야 적용할 수 있습니다.", "0으로 나눌 수 없습니다.", "999,999,999원까지 적용할 수 있습니다.")

### SC-08: 지출 상세 바텀시트

SC-03·04·05 목록에서 항목을 누르면 연다. `?expense={id}`

#### 규칙

- URL로 연다. 새로고침해도 시트가 다시 열리고, 뒤로 가기로 닫힌다.
- 대상이 없으면(404) 시트를 열지 않고 알림 다이얼로그 "이미 삭제된 기록입니다" → [확인] 후 `expense` 쿼리 제거 + 목록 다시 불러오기.
- [수정] → `/expenses/[id]/edit`. 오프라인이어도 열린다.
- 새로고침으로 열 때는 시트 안에 스켈레톤을 보여준다.
- [삭제]
  - 반복 없는 기록: 확인 다이얼로그 "이 기록을 삭제하시겠습니까?" → [삭제]
  - 반복 기록: SC-09 범위 선택 → 확인 다이얼로그
  - 성공: 시트 닫기 + 목록 다시 불러오기
  - 실패: 알림 다이얼로그 "삭제하지 못했습니다", [확인] 후 시트 유지
  - 오프라인이면 [삭제] 비활성

#### 페이지 구성안

- 카테고리 아이콘 + 제목: 아이콘 옆에 제목, 카테고리 이름은 제목 아래 작게
- 금액 (크게)
- 날짜 `2026년 10월 18일 (일)`
- 내용 (있을 때만, 줄바꿈 유지)
- 반복 정보 (반복 기록만)
  - 정기지출: `매달 18일 · 계속` 또는 `2026년 10월 ~ 2027년 3월`
  - 할부: `할부 3/12회 · 총 400,000원` + 기간
- 제목은 말줄임 없이 줄바꿈
- 하단 버튼: [삭제] · [수정]

### SC-09: 반복 건 수정·삭제 범위 선택

SC-06에서 반복 기록을 저장할 때, SC-08에서 반복 기록을 삭제할 때 연다.

#### 규칙

- 선택지 (라디오, 기본값 "이번 건만"):
  - 이번 건만
  - 이후 전체: 선택한 건과 그 뒤 전체 (할부는 남은 회차)
  - 이 건부터 N개월: N은 1 ~ 남은 건수
- 선택에 따라 영향받는 범위를 미리 보여준다: `2026년 10월 ~ 2027년 3월 (6건)`, 계속 반복이면 `2026년 10월부터 계속`.
- 범위 수정 시 날짜를 바꿨으면, 각 건의 결제일을 바꾼 날짜의 일로 옮긴다 (그 일이 없는 달은 [말일](#공통-정책값)). 제목·카테고리·금액·내용은 범위 안 모든 건에 같게 적용한다.
- 저장·삭제가 실패하면 알림 다이얼로그 [확인] 후 범위 시트와 선택값을 유지한다. 다시 누를 수 있다.
- 삭제 확인 문구: `{N}건을 삭제하시겠습니까?`. 계속 반복하는 정기지출의 "이후 전체" 삭제는 `이 건부터 반복이 종료됩니다. 삭제하시겠습니까?`.

#### 페이지 구성안

- 제목: `반복 기록 수정` / `반복 기록 삭제`
- 라디오 3개 (+ N 입력) · 범위 미리보기
- [취소] · [저장] 또는 [삭제](danger)

### SC-10: 설정

`/settings`

#### 규칙

- 화면 모드는 이 기기에만 저장한다 (계정에 저장하지 않는다). 기본값은 시스템 설정 따름. 바꾸면 즉시 적용.
- 로그아웃은 확인 없이 바로 실행한다 → `/login`. 네트워크 오류로 요청이 실패해도 이 기기의 로그인 정보를 지우고 `/login`으로 보낸다.
- 회원 탈퇴는 확인 다이얼로그를 거친다.
  - 문구: "계정과 지출 기록 {N}건이 모두 삭제되며 되돌릴 수 없습니다."
  - "위 내용을 확인했습니다" 체크 → [탈퇴하기](danger) 활성화
  - 진행 중: [취소]·[탈퇴하기] 모두 비활성, 다이얼로그를 닫을 수 없다
  - 성공: 세션 종료 → `/login?reason=withdrawn`. 로그인 화면이 탈퇴 완료 안내 문구를 보여준다
  - 실패: 알림 다이얼로그 "탈퇴하지 못했습니다", [확인] 후 설정 화면 그대로. 탈퇴는 한 번에 처리되어 일부만 지워진 상태가 생기지 않아야 한다 (3단계)

#### 페이지 구성안

- **계정**: Google 이메일
- **화면 모드**: 시스템 설정 따름 / 라이트 / 다크
- [로그아웃]
- [회원 탈퇴] (화면 맨 아래, 눈에 덜 띄게)
