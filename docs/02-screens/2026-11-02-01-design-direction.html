다씀 디자인 방향 시안

레거시(다씀 v1)와 초록 계열 후보 A·B를 같은 화면 조각으로 비교한다. 색·글꼴 방향 하나를 고르기 위한 문서이고, 확정된 토큰은 디자인 토큰 문서에 정리한다. 2026-11-02

이미 정한 것

  • 버튼 종류: primary filled · secondary filled(옅은 초록 면 + 초록 글자) · primary outline · secondary line · text(밑줄) · danger · disabled · gray(회색 면 + 회색 글자). positive는 두지 않는다.
  • danger 버튼은 모두 채움(filled). SC-08 [삭제]도 채움으로 바꾼다.
  • 달력: 일요일만 빨강, 토요일은 회색으로 낮춘다. 오늘 = 테두리, 선택 = 채움.
  • 로고: 레거시처럼 "다씀"을 Tenada로 쓴다 (+ 연필 아이콘).
  • 카테고리 아이콘은 사용자가 직접 넣는다. 시안의 아이콘 자리는 비워 둔다.
  • 금액은 초록이 아니라 기본 글자색. 초록은 브랜드·선택·주요 동작에만 쓴다.
시안 전체 글꼴:

1. 한눈에 비교

대비는 WCAG 기준. 글자는 4.5:1 이상이어야 한다(비활성은 예외).

2. 방향별 화면 조각

왼쪽부터 라이트 달력 · 다크 달력 · 라이트 버튼/다이얼로그 · 다크 버튼/다이얼로그. 버튼 왼쪽 작은 글씨는 그 버튼 글자의 대비.

3. 글꼴 비교

숫자 열은 오른쪽 정렬. "고정폭"은 font-variant-numeric: tabular-nums를 켠 상태다. 자릿수가 세로로 맞는지 본다.

4. 고를 것

  • 색 방향: A · B 중 하나 (또는 섞기: 예 "B의 버튼 + A의 다크 모드")
  • 글꼴: Pretendard · SUIT · Noto Sans KR 중 하나 (숫자 고정폭 정렬 확인)
