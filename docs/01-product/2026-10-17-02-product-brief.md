# 서비스 기획: 다씀 리뉴얼

> 1단계 산출물. 구버전 분석은 `2026-10-17-01-legacy-analysis.md` 참고.
> 상태: 1단계 결정 완료, 사용자 리뷰 대기.

## 1. 목표

- **용도**: 본인 실사용. 홍보 계획은 없다.
- **운영**: 무료 요금제로 운영한다.
- **포트폴리오**: 기획부터 개발까지 AI를 어떻게 제어하며 완성도를 높였는지 과정을 남긴다.

## 2. 서비스 원칙

**"내가 얼마 썼는지만 알고 싶을 때."** 구버전의 기조를 유지한다.
- 지출 기록과 조회가 중심이다.
- 실사용에 꼭 필요한 정기지출·할부, 간단한 월간 통계만 더한다.
- 예산, 수입, 계좌·카드 연동은 넣지 않는다.

## 3. 대상 플랫폼

- 모바일 웹 + PWA(홈 화면에 설치) 우선
- 데스크톱에서는 모바일 레이아웃을 가운데 정렬해 보여준다.
- 오프라인 기록 기능은 없다. 온라인일 때만 기록한다.

## 4. MVP 기능

### 4-1. 인증
- Google 로그인만 제공한다. 체험하기·데모 모드는 없다.
- 로그아웃
- 회원 탈퇴: 계정과 모든 지출 데이터를 삭제한다.

### 4-2. 지출 기록
- **필드**: 날짜, 제목, 카테고리, 금액, 내용(선택)
- 등록, 상세 조회, 수정, 삭제
- 월간 달력에서 날짜를 골라 그 날짜로 바로 등록

### 4-3. 계산 기능 (금액 입력 보조)
- 더하기, 빼기, 곱하기, 1/n
- 1/n 끝전 처리: 10원·100원 단위로 올림·버림
- 계산식을 내용(메모)에 기록 (예: `36,000 ÷ 3`)

### 4-4. 정기지출·할부
- **정기지출**: 매달 결제일에 반복되는 지출
- **할부**: 총 회차가 있는 지출. 회차(예: 3/12)를 표시
- **결제일이 없는 달**: 결제일이 그 달에 없으면(예: 31일 결제, 30일까지인 달) 그 달 말일로 처리한다.
- **적용 범위**: 생성, 수정, 삭제 모두 아래 세 가지 범위를 선택할 수 있다.

| 범위 | 생성 | 수정·삭제 |
|---|---|---|
| 이번 건만 | 이번 달 한 건만 | 선택한 건만 |
| 이후 전체 | 계속 반복 | 선택한 건과 그 이후 전체 |
| 기간 지정 | 지정한 개월 수만큼 | 지정한 기간에 속한 건 |

> "기간 지정"의 입력 방식(개월 수, 시작·끝 월 등)은 2단계 화면 구성안에서 정한다.

### 4-5. 조회
- **월간 달력** (메인 화면)
  - 날짜별 지출 합계, 월 합계
  - 월 이동, 연·월 직접 선택
  - 날짜를 고르면 그날의 내역 목록
- **카테고리별** (월간 통계 포함)
  - 월 선택, 카테고리 필터(전체 포함)
  - 월 합계, 카테고리 비중, 지난달 대비 증감
  - 내역 목록

### 4-6. 카테고리 (고정 10개)

| 카테고리 | 포함 범위 |
|---|---|
| 식비 | 식사, 장보기, 카페·간식 |
| 가전 | 전자제품, 생활가전 |
| 교통 | 대중교통, 택시, 주유, 주차 |
| 의료 | 병원, 약국 |
| 의류 | 옷, 신발, 잡화 |
| 미용 | 미용실, 화장품 |
| 문화 | 공연, 영화, 여행, 취미 |
| 교육 | 학비, 강의, 도서 |
| 생활 | 주거비, 공과금, 통신비, 구독료, 생활용품 |
| 기타 | 위에 속하지 않는 지출 |

## 5. MVP에서 제외

| 항목 | 이유 |
|---|---|
| 주간·일간 화면 | 실사용에서 보지 않음. 월간 달력의 날짜 선택으로 대신함 |
| 체험하기·데모 모드 | 본인 실사용 목적. 포트폴리오는 스크린샷·영상으로 대신함 |
| 예산, 수입, 계좌·카드 연동 | 서비스 원칙에서 벗어남 |
| 할인율, 환율 환산 계산 | 사용 빈도가 낮음 |
| 사용자 정의 카테고리 | 고정 목록으로 충분함 |
| 오프라인 기록 | 필요 없음 |
| CSV 내보내기 | MVP 이후 검토 (8장 TODO) |

## 6. 핵심 사용자 흐름

1. **첫 사용**: 접속 → Google 로그인 → 이번 달 월간 달력 (비어 있음)
2. **지출 기록**: 월간 달력에서 날짜 선택 → 등록 → 날짜·제목·카테고리·금액 입력 (필요하면 계산 기능 사용) → 저장 → 달력에 반영
3. **정기지출 등록**: 등록 화면에서 정기지출·할부를 선택 → 결제일, 횟수 또는 회차 입력 → 저장 → 해당 월들의 달력에 반영
4. **이번 달 확인**: 월간 달력에서 월 합계와 날짜별 합계 확인 → 날짜 선택 → 내역 → 상세 → 수정·삭제
5. **소비 돌아보기**: 카테고리별 화면 → 월 선택 → 비중과 지난달 대비 증감 확인 → 카테고리 필터로 내역 확인

## 7. 구버전 데이터 이전

구버전 데이터는 본인 데이터뿐이므로, 새 서비스에 계정을 만든 뒤 그 계정으로 모두 옮긴다.
- 대상: 구버전 Firestore `expend` 컬렉션 중 본인 표시 이름으로 저장된 문서
- 변환:
  - 금액: 문자열 → 숫자
  - 카테고리: 학비 → 교육, 문화생활 → 문화. 나머지 7개는 이름이 같다.
- 방법(구버전 데이터를 내보내는 방식, 이전 스크립트)은 3단계 데이터 아키텍처에서 정한다.
